# autonomous-agentic-rag

Подбор запросов к модели, способов поиска и правил работы агентов требует повторных проверок на одних и тех же задачах. Цикл самоулучшения RAG позволяет сравнивать варианты этих правил по нескольким критериям и передавать человеку варианты с разными компромиссами. В примере из медицинской области агенты работают с несколькими источниками знаний, а окончательное решение принимает человек.

## Возможности

- Собирает результат работы специализированных агентов по заданным стандартным рабочим процедурам (SOP); взаимодействие агентов организовано через LangGraph.
- Оценивает результат по нескольким критериям, включая точность, выполнимость и соответствие требованиям, и формирует вектор оценок.
- Анализирует оценки отдельным агентом-диагностом, чтобы найти слабое место в процедуре и предложить объяснение его причины.
- Создаёт варианты SOP на основе диагностики и повторно выполняет задачу для проверки изменений.
- Выделяет фронт Парето среди проверенных вариантов: процедуры, которые нельзя улучшить по одному критерию без ухудшения по другому.
- Использует LangSmith для трассировки взаимодействий агентов и разбора результатов выполнения.

## Установка

Работа ведётся в Jupyter Notebook. Команды ниже запускайте из локального каталога проекта. Пример рассчитан на Linux или macOS; в Windows окружение активируется командой `.venv\Scripts\activate`.

```bash
cd autonomous-agentic-rag
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install jupyterlab
```

Это установка среды для открытия блокнотов. Зависимости вычислений устанавливайте по ячейкам настройки выбранного блокнота: в описанном подходе используются LangChain, LangGraph и LangSmith. Точные версии и полный список пакетов в исходных данных не указаны.

Для локальных моделей потребуется отдельно установить и запустить Ollama. Имена моделей берите из конфигурации блокнота. Если используете трассировку LangSmith, настройте учётные данные перед выполнением ячеек и проверьте, какие данные будут отправляться во внешний сервис.

## Использование

Запустите JupyterLab из каталога `autonomous-agentic-rag`:

```bash
jupyter lab --notebook-dir=. --port=8888 --no-browser
```

Откройте адрес с токеном из вывода команды, затем выберите блокнот проекта. Отдельный консольный интерфейс `autonomous-agentic-rag` здесь не предполагается.

Выполняйте ячейки по порядку:

1. Настройте подключение к моделям и подготовьте хранилища знаний. Медицинский пример использует научные публикации PubMed, рекомендации FDA и этические принципы.
2. Задайте исходные SOP и входную задачу, затем выполните пробный запуск группы агентов.
3. Запустите оценку результата и цикл изменения SOP. Каждый новый вариант должен пройти повторное выполнение задачи и оценивание.
4. Сравните варианты на фронте Парето и выберите подходящий с учётом требований задачи.

**Рост оценок сам по себе не подтверждает медицинскую корректность результата.** Проверяйте источники и выводы; окончательное решение остаётся за человеком. Не используйте чувствительные медицинские данные без проверки условий их обработки моделями и системой трассировки.
